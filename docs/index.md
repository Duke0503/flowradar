## Original sources

These two files in the project root were the input for everything above. They are in Vietnamese
and English mixed, and they are not edited.

- `Khởi động dự án Order Flow.pdf`: a design conversation (17 pages) covering the product idea,
  architecture, tech stack, repositories, protocols, and the first Python code for layers 1 to 3.
- `Open Source Trading Architecture Research.docx`: a research report on 42 open-source projects
  and the patterns worth inheriting.

## Approved decisions so far

| Code | Decision |
|---|---|
| D1 | FlowRadar publishes trade signals only and never places orders |
| D2 | Win rate counts only setups that became active; invalidated and expired setups are tracked separately |
| D3 | The Python Quant Engine owns value area computation and the TradeSetup lifecycle |
| D4 | The MVP is public and read-only, with no login or billing |
| D5 | Rejected AI setups are stored with a rejection reason and never shown to users |

Full text, rationale and consequences are in `../.context/decisions/`.
